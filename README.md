# data_science_assignment1_employee_management
The Employee Management System is a basic Python project designed to manage employee records efficiently. This system helps in storing, updating, searching, and displaying employee information using simple programming concepts. It is a console-based application and is suitable for beginners learning Python.


Features
Add new employees with unique Employee ID
View all employee records
Search employee details by ID
Menu-driven console interface
Technologies Used
Python 3
Data Structure
Employee data is stored using a dictionary with Employee ID as the key and employee details as values.
